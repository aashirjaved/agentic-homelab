# Skills

Skills are reusable agent instructions. They should work for local agents such as OpenClaw and Hermes, and adapt cleanly to Claude, Codex, Cursor, and other coding agents.

## Skill Rules

- Start with read-only discovery.
- Load the safety harness before privileged work.
- Prefer inventory, policy, and MCP manifests over guessing.
- Ask for approval before writes, restarts, network exposure, storage changes, or credential access.
- Verify externally and record what changed.
