# agentic-homelab v0.2.1 — Real Homelab Discovery

v0.2.1 is the dogfood release. The Doctor was run end to end against a real,
messy multi-host lab spanning Proxmox, Docker Compose, NFS, ZFS, private LAN,
and Tailscale paths. The failures found in that run were fixed in the product,
not documented as future work.

## Highlights

- Discover declared and explicit SSH targets in parallel with fixed read-only
  Docker, filesystem, and Proxmox commands.
- Accept keyed operator inventories directly; a second flattened inventory is
  no longer required.
- Reconcile declared services and mounts with live Compose and NFS evidence.
- Infer service → host → NFS mount → NAS → backing filesystem chains.
- Keep the controller out of a remote graph with `--no-local`.
- Distinguish public internet endpoints from private LAN and Tailscale CGNAT
  addresses.
- Distinguish undeclared stopped artifacts from declared service outages.
- Keep incident traversal causal and component-specific.

## Install

```bash
pipx install "git+https://github.com/aashirjaved/agentic-homelab.git@v0.2.1"
homelab doctor
```

## Multi-host example

```bash
homelab doctor \
  --inventory inventory.yaml \
  --no-local \
  --ssh apps=root@apps.internal \
  --ssh media=root@media.internal \
  --ssh-identity ~/.ssh/homelab_readonly
```

SSH remains non-interactive, timeout-bounded, and subject to normal known-host
verification. The Doctor makes no infrastructure changes.

## Live verification

- 70 services
- 105 storage systems
- 17 Compose stacks
- 15 Docker networks
- 394 relationships
- zero unresolved graph edges
- 27 of 27 controller-scoped endpoints reachable

The healthy-service investigation traced Jellyfin through its Docker host, NFS
mount, NAS host, and backing ZFS filesystem, and correctly concluded that no
current incident was established. The generated share bundle passed checks for
private IPs, local usernames, and SSH identity paths.
