# agentic-homelab v0.2.0 — Homelab Intelligence

Your homelab, explained.

v0.2.0 turns the repository into an installable, read-only homelab intelligence
tool. It discovers local Docker and Compose topology, host mounts, NFS/SMB
storage, scoped Proxmox resources, network evidence, and declared service
health. It connects those observations into a dependency graph and keeps
unresolved relationships visible.

## Highlights

- `homelab doctor` discovers and explains the current lab.
- `homelab investigate COMPONENT` ranks deterministic incident hypotheses and
  shows evidence, impact, and read-only verification steps.
- `homelab changes`, `homelab recovery`, and `homelab updates` have focused
  Markdown and JSON output contracts.
- `homelab share OUTPUT` creates a redacted four-file diagnostic bundle.
- Compose projects, service dependencies, Docker networks, named volumes,
  bind-mount backing storage, NFS/SMB serving hosts, Proxmox guests, and guest
  storage backends contribute inferred graph edges.
- A reproducible incident demo is generated by the real CLI from a checked-in
  fixture.

## Install

```bash
pipx install "git+https://github.com/aashirjaved/agentic-homelab.git@v0.2.0"
homelab doctor
```

The release also includes a wheel and source archive as GitHub assets.

## Evidence boundary

- Zero infrastructure writes are implemented by the doctor.
- Recovery results score observed and supplied evidence; they do not perform a
  restore or inspect backup contents.
- Update results assess supplied update research; they do not fetch release
  notes or vulnerability feeds.
- The first `homelab changes` run records a baseline. Proxmox recent tasks can
  contribute events immediately when configured.
- Missing access and unresolved topology are reported as unknown, not healthy.
