# Design Notes

This repository borrows structure from three common GitHub project families:

- awesome lists: discoverable categories and strong README-first navigation
- homelab-as-code repos: playbooks, examples, docs, and reproducibility
- MCP collections: independent packages with local README and metadata

The result is intentionally modular. A user with only Docker should not need the Proxmox package. A user running local agents should not need Kubernetes.
